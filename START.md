# Быстрый старт (для владельца сервера)

# Вариант БЕЗ ПК — только iPhone (сервер работает прямо на телефоне)

1. Установи из App Store бесплатное приложение **iSH Shell**
2. Открой iSH и выполни (каждая строка — Enter):
   ```
   apk update
   apk add python3
   ```
   Это займёт несколько минут, жди до конца.
3. В Safari открой репозиторий, в списке веток (слева от кнопки Code) выбери
   ветку `vibe/player-persistence-1e686a`, затем Code → Download ZIP.
   Туда же скачай оригинальный IPA (ссылка в README).
   Открой «Файлы» → скачанный ZIP → Поделиться → **Копировать в iSH**
4. В iSH:
   ```
   unzip HayDay*.zip
   cd HayDay*/
   sh START_IPHONE.sh
   ```
   Когда сервер напишет, что слушает порт — сворачивать его не нужно.
5. Не выходя из iSH, пропатчи IPA (он уже должен лежать в iSH: если нет —
   Поделиться → Копировать в iSH из «Файлов»):
   ```
   python3 patcher.py "Hay Day 1.5.42 (772.14583.4279).ipa" haydaypatched.ipa 127.0.0.1
   ```
6. Открой «Файлы» → На моём iPhone → iSH → папка сервера → `haydaypatched.ipa`
   → Поделиться → подпиши и установи через eSign
7. Запусти игру. Сервер крутится в iSH: если связь подвиснет, на секунду
   вернись в iSH и снова в игру — она продолжит.

Готово. Больше от тебя ничего не требуется — прогресс игры сохраняется
в папке `Database` внутри проекта на телефоне.

# Вариант с ПК

## 1. Запусти сервер (ПК)

- **Windows:** двойной клик по `START_WINDOWS.bat`
- **Mac / Linux:** в терминале `sh START_MAC_LINUX.sh`

Скрипт сам установит зависимости, определит твой IP и запустит сервер.
Запомни строку `[*] LAN IP: x.x.x.x` — она понадобится один раз для патча клиента.
Окно с сервером держи открытым, пока играешь.

## 2. Пропатчи игру (ПК)

Положи оригинальный IPA в папку сервера, затем:

```
python3 patcher.py "Hay Day 1.5.42 (772.14583.4279).ipa" haydaypatched.ipa
```

IP подставится автоматически. Получится файл `haydaypatched.ipa`.

## 3. Установи игру (телефон)

1. Перекинь `haydaypatched.ipa` на телефон
2. Подпиши и установи через eSign
3. Убедись, что телефон и ПК в одной Wi-Fi сети

Запускай игру. Всё, сервер уже работает.
